- Plan 003 lands before Plan 004 because duplicate consolidation must reuse the same atomic, recoverable commit path rather than introduce another destructive writer.
- Plans intentionally keep `data/applications.md` as the user-facing source. Structured database migration is not required for this reliability tranche.

## Findings considered and rejected

- Missing build script: not a defect for source-run `.mjs` CLIs.
- Missing `type: module`: not required because entrypoints use `.mjs`.
- Local-parser command injection: rejected; implementation uses `execFile` with an argument array and no shell.
- Greenhouse redirect SSRF: rejected for that provider; hostname is allowlisted and redirects are disabled.
- Shared JavaScript counters under provider concurrency: not a data race because mutations occur without `await` on one event-loop thread.
- Multi-row tracker-addition files as a required feature: rejected; current contract explicitly requires one row per file. Invalid multi-row input should fail clearly, not be supported implicitly.
